W12 P1: `cloud-sync-screen.tsx` perform() falls back to `failure.message` for nonzero-status Error objects independent of language. This is a second path distinct from generic Persian fallback: unlocalized implementation text may reach either language. The same screen exposes account ID and cursor through sync.account/sync.progress; retain support diagnostics only where they help a user make a decision, and prefer meaningful pending/current/recovery status for routine presentation. Do not capture these IDs from private accounts. Proposed error mapping must retain machine codes and version/cursor semantics internally.

## Localization and factual safety

English fallback and typed dictionary help coverage; first-strong-character direction and FSI/PDI interpolation isolation are intentional. Language preference is persisted at device scope; deck language/alignment and speech are independent. UI baseline remains LTR with explicit RTL handling; avoid global mirroring. Verify Persian with English decks, English with Persian decks, centered content, punctuation, amounts, dates and time. Current Intl fa-IR/en-US formatting is technical behavior, not an approved complete terminology/calendar policy.

Use a single visible vocabulary for طرح/اشتراک, دسته/کارت, مرور/مطالعه, همگام‌سازی/پشتیبان‌گیری and بازیابی خرید. Preserve distinctions: sync is not a backup artifact; artifact creation is not app restore; SMS request is not delivery; OTP verification is not sign-in; catalog selection is not payment; pending/unknown is not failure. Avoid unconditional “no payment occurred” after uncertain payment completion. Retain server-authoritative amounts, durations, non-renewal disclosure, expiry, receipt IDs and data-preservation limitations.

English literal descriptions in transfer formatHelp require reachability verification: the declarations alone do not prove they render untranslated. Dictionary ledger flags legacy/unknown usage rather than declaring all keys user-visible. Replacement examples above are proposed, not approved or applied. A bilingual editorial review and native text/announcement verification remain required before release.
