# Feedback lifecycle contracts

2026-11-15, implementation under D-28. This register defines current producer behavior and required QA. The accompanying `evidence/feedback-lifecycle.json` identifies every direct presentation producer (component instance and explicit announcement) by source/line, trigger expression and lifecycle profile. Nested generic components inherit the profile below; inventory is not a rendered/native pass. No one-to-one AppError-to-surface mapping is used.

## Validation limits

Source/automated evidence can verify trigger branches, identifiers, guard behavior, callback availability and local announcements. It does not establish rendered hierarchy, actual TalkBack speech, touch bounds, focus restoration, overlay contrast or provider/OS delivery. The final QA matrix in RUNTIME_VERIFICATION_PLAN.md remains open. No historical release gate is closed by migration away from a modal on some producers; the retained modal still needs actual theme/focus verification.
